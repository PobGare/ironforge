# IRONFORGE

IRONFORGE is a multi-page fitness and performance website focused on training, coaching, nutrition, supplements, assessments, and support.

## Features

- Multi-page website structure
- Responsive layouts
- Training and coaching sections
- Nutrition and supplement content
- Assessment and support pages
- Custom front-end interactions
- Canvas API effects
- WebGL visual effects

## Built With

- HTML
- CSS
- JavaScript
- Canvas API
- WebGL
